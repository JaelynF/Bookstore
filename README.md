# Bookstore

The Book Nook is a single-page bookstore website designed to showcase a curated collection of books across multiple genres. The site features a full screen hero slideshow, organized book catalogs, an about section, and a contact form.
This project was built as part of a web development course focused on responsive design and Bootstrap 5 layout principles.

Built With:
- HTML5
- Bootstrap 5
- Google Fonts (Playfair Display, Lato)
